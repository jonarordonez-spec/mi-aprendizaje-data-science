# 🚕 Predicción de Propinas - Taxis NYC

## 📊 Descripción
Modelo de Machine Learning para predecir propinas en taxis de Nueva York usando XGBoost. Proyecto basado en datos reales con 5 millones de registros.

**Inspirado en:** [Mariya Sha - YouTube Tutorial](https://www.youtube.com/watch?v=F_8RKstP2X8)

## 🎯 Resultados Destacados
- **Precisión (R²):** 94.9%
- **Error promedio:** ±$0.92 por propina
- **Feature principal:** Tarifa del viaje (`fare_amount`)

## 🛠️ Tecnologías
- Python · Pandas · XGBoost · Scikit-learn · Matplotlib
