# Clase 5: Álgebra Lineal con NumPy

## 📚 Lo que Aprendí en esta Clase

### 🔢 Vectores en NumPy
- Creación de vectores con `np.array()`
- Vectores especiales: `np.ones()`, `np.arange()`
- Operaciones aritméticas con vectores
- Producto punto con `np.dot()`
- Cálculo de norma con `np.linalg.norm()`

### 🧮 Matrices en NumPy
- Creación y manipulación de matrices
- Operaciones con matrices: suma, resta, multiplicación
- Multiplicación por escalar
- Propiedades: `.shape`, `.size`
- Matriz identidad con `np.eye()`
- Matriz transpuesta
- Matriz inversa con álgebra lineal

### ⚡ Diferencias Listas Python vs Arrays NumPy
- Operaciones element-wise en NumPy
- Eficiencia en cálculos matemáticos
- Funciones especializadas para álgebra lineal
