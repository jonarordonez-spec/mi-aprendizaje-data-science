# Clase 6: Estadística Descriptiva y Visualización con Python

## 📚 Lo que Aprendí en esta Clase

### 📊 Estadística Descriptiva
- **Medidas de Tendencia Central**: Media, Mediana, Moda
- **Medidas de Dispersión**: Rango, Varianza, Desviación Estándar
- **Cuantiles**: Cuartiles, Deciles, Percentiles
- **Aplicación práctica** con datasets reales usando Pandas y NumPy

### 📈 Visualización de Datos
- **Gráficas básicas**: Líneas, Barras, Pastel, Dispersión
- **Personalización avanzada**: Colores, estilos, marcadores
- **Gráficas estadísticas**: Histogramas, Boxplots
- **Exportación** de gráficas en múltiples formatos

### 🔢 Álgebra Lineal (Repaso)
- **Vectores y Matrices**: Operaciones básicas
- **Producto escalar** y normas
- **Matrices especiales**: Identidad, Inversa, Transpuesta
- **Determinantes** y aplicaciones
